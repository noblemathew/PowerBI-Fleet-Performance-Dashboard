📊 Overview

This project presents an interactive Fleet Performance & Delivery Efficiency Dashboard built using Power BI. It provides insights into delivery performance, cost efficiency, fuel trends, and key operational factors influencing logistics outcomes.

The dashboard is designed to help stakeholders make data-driven decisions to optimize fleet operations and reduce costs.

🎯 Key Features
📦 On-Time Delivery Performance
Visual comparison across different destinations
Helps identify delays and improvement areas

⛽ Fuel Efficiency Trend
Time-based analysis of fuel consumption
Detects inefficiencies and anomalies

💰 Cost per KM Analysis
Breakdown by vehicle type (Truck, Van, Mini-Truck)
Enables cost optimization strategies
🛠 Maintenance Cost Insights
Distribution of maintenance cost by vehicle type
⏱ Estimated Delivery Time
Average delivery time based on speed assumptions

🧠 Key Influencers (AI Visual)
Identifies factors affecting delivery status (On-Time vs Delay)
